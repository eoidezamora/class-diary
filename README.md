# Class Diary · Básico A2 · EOI de Zamora

Diario de clase público del grupo Básico A2 (curso 2026-27).

- Contenido: `content/AAAA-MM.md` (un archivo por mes, sesión más reciente arriba).
- Deberes: una línea `HW[Título|Descripción][Título|Descripción]`.
- Materiales: `content/materiales.json` + PDF del alumnado en `materiales/`.
- Notions, Grammar y Vocabulary: `content/vocabulary.json` + `content/vocabulary/<id>.md` (→ `vocabulary.html`, `vocab-<id>.html`), además de `content/notions.json` y `content/grammar.json` (cada ref = [sesión, etiqueta, inicio del id del apartado]) y un artículo por punto en `content/notions/<id>.md` y `content/grammar/<id>.md`. Se generan `notions.html`, `grammar.html`, `notion-<id>.html` y `grammar-<id>.html` (artículo + apartados de cada sesión).
- Generar la web: `python3 build.py` (necesita `pip install markdown markdown-it-py`).
