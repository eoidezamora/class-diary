# Class Diary · Básico A2 · EOI de Zamora

Diario de clase público del grupo Básico A2 (curso 2026-27).

- Contenido: `content/AAAA-MM.md` (un archivo por mes, sesión más reciente arriba).
- Deberes: una línea `HW[Título|Descripción][Título|Descripción]`.
- Materiales: `content/materiales.json` + PDF del alumnado en `materiales/`.
- Notions: `content/notions.json` (cada ref = [sesión, etiqueta, inicio del id del apartado]) y un resumen por notion en `content/notions/<id>.md`. Se generan `notions.html` y `notion-<id>.html` (resumen + apartados de cada sesión).
- Generar la web: `python3 build.py` (necesita `pip install markdown markdown-it-py`).
