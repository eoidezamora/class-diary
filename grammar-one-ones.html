one / ones one and ones

The red one, the blue ones: para no repetir un nombre. Primero, todo junto; después, lo que vimos en cada sesión.

ArtículoTodo juntoSesión 15one / ones
ArtículoTodo lo visto, explicado y ordenado

Cuando ya está claro de qué hablamos, en español quitamos el nombre: «el coche rojo y el azul». En inglés no podemos dejar el adjetivo solo; necesitamos una palabra que ocupe el lugar del nombre: one o ones.

1. one para el singular, ones para el plural

We have two cars. The red one is a Peugeot and the blue one is a Renault.
We have four cars. The red ones are mine and the blue ones are my brother's.

Nunca decimos the red is a Peugeot: el adjetivo necesita algo detrás.

2. Con this, that, which

También sustituye al nombre detrás de los demostrativos: This watch is very expensive. → This one is very expensive. Y para preguntar: Which one? (¿Cuál?) · Which ones? (¿Cuáles?).

En resumen: adjetivo o demostrativo + one (singular) / ones (plural), para no repetir el nombre.

Sesión 15jueves 26 de noviembre

one / ones: para no repetir

Cuando ya sabemos de qué hablamos, cambiamos el nombre por one (singular) u ones (plural):

This watch is very expensive. → This one is very expensive.
We have two cars. The red one is a Peugeot and the blue one is a Renault.
We have four cars. The red ones are mine and the blue ones are my brother's.

  • one sustituye a un nombre en singular (car), ones a un nombre en plural (cars).
  • Va detrás de un adjetivo o de this / that / the: the red one, this one, the big ones.
